# Batlet website

Static website for [Batlet](https://github.com/niceit/Batlet). GitHub Pages serves `index.html` directly from the repository root on the `main` branch. No build step or external packages are needed.

To preview locally, open `index.html` in a browser or run `python3 -m http.server` from this directory.
